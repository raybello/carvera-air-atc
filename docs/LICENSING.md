| Carvera Community Firmware / Controller | See each repo (Smoothieware-derived, GPL-family) | Link to them; if we ship modified firmware, comply with its license (publish source) |
| "Carvera", "Makera" | Trademarks of Makera | Say "for Makera Carvera Air" or "compatible with". No logos, no implied endorsement |
| Everything in `cad/custom/`, `electronics/`, `firmware/pico/`, docs we write | Ours | Free to sell. Choose a license in Phase 3 (suggest: hardware CERN-OHL-S or closed, docs CC BY) |

**Phase 2 rule:** the sellable kit must be a **clean-room redesign**. New CAD drawn from our own measurements and interface facts, without importing, tracing or editing Warioo's geometry. Optional courtesy: tell Warioo and credit them as inspiration, or ask about a commercial license if we'd prefer to build on their files.
